# onem2mlib

An open source implementation of a Python library for the oneM2M standard, providing a simple and intuitive interface for developers to interact with oneM2M compliant CSEs (Common Service Entities). The library abstracts away the complexities of the oneM2M protocol, allowing developers to focus on building applications that leverage the capabilities of oneM2M.

## Introduction

This library provides a high-level API for interacting with oneM2M compliant CSEs, enabling developers to easily create, retrieve, update, and delete resources. Thie library is designed to be extensible and modular, allowing developers to easily add support for new features and resource types as needed.


## Installing

Install with pip or your favorite PyPI package manager.

	python -m pip install onem2mlib
